# Marketly — интернет-магазин (frontend demo)

**React 19 · TypeScript · REST API · localStorage · Vite · Vitest**

Полноценный учебный прототип витрины. На странице есть адаптивная сетка товаров, поиск, фильтры, сортировка, избранное, карточка товара и корзина. **Реальные платежи и оформление заказов отсутствуют.**

## Возможности

- Загрузка товаров с публичного [DummyJSON API](https://dummyjson.com/docs/products) (`GET /products?limit=40`).
- Экран загрузки и **локальные резервные товары**, когда API недоступен (в `src/fallback.ts`).
- Поиск по названию и описанию, выбор категории, сортировка по цене и рейтингу.
- Избранное и корзина с хранением в `localStorage`.
- Модальное окно товара с описанием, рейтингом и остатком.
- Изменение количества, расчёт итоговой стоимости и демонстрационная (неплатёжная) покупка.
- Отзывчивый мобильный интерфейс, семантические элементы и ARIA-метки элементов управления.
- Unit-тесты фильтров, сортировки и корзины.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте URL из консоли (обычно http://localhost:5173).

```bash
npm test
npm run build
npm run preview
```

## Структура

```
public/illustrations/   # локальная SVG-графика резервных товаров
src/
  App.tsx              # UI, fetch, корзина и модальные окна
  catalog.ts           # модели данных, фильтры, сортировка, цены
  catalog.test.ts      # unit-тесты
  fallback.ts          # резервный каталог
  styles.css           # адаптивный дизайн
```

## Как работает интеграция

Приложение загружает каталог из DummyJSON. Если запрос завершается ошибкой либо истекает таймаут, остаётся доступным встроенный набор демонстрационных товаров. Для реального интернет-магазина потребовались бы собственный backend, авторизация, актуальный склад, безопасная обработка платежей и валидация данных на сервере.

Цены на API представлены в USD, как и в интерфейсе — конвертация в рубли отсутствует. Нельзя принимать итоговую кнопку за реальное оформление заказа.

## Что полезно объяснить на собеседовании

- Почему корзина представлена массивом `CartItem[]`, а не копиями полных товаров.
- Почему функции фильтрации/сортировки вынесены в отдельный модуль и протестированы.
- Как работает `AbortController`, fallback и синхронизация с `localStorage`.
- Что необходимо для реальной оплаты, защита от доверия к client-side ценам.

## Происхождение

Демонстрационное приложение, не связанное с реальным магазином. При публикации следует честно обозначать участие AI в подготовке кода, если оно было.
